# Pahrump Hills science activities v3

Adds four proposed rock-chip sampling follow-ups to the unchanged v2 source
snapshot. Four equipment capabilities, three objectives and 14 total activities.

Sources, position handling, equipment assumptions and verification:
[rock-sampling source review](../../../../../docs/terrain/rock-sampling-v3.md).

Regenerate from the repository root:

```sh
python scripts/terrain/export_rock_sampling_v3.py
```

`provenance.json` pins the earlier collection and review inputs and the runtime
output hash. A sampling proposal does not establish a collectable rock, an exact
footprint, a laboratory finding or a certified Mars EVA procedure.
